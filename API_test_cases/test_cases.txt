Task 1: API Testing (Postman)

Assumptions
Base URL: https://api.rewardz.com
APIs use JSON format
Authentication token required after login
Cart operations require logged-in user

1. Login API Testing
Endpoint

| Test Case ID | Scenario                          | Expected Result              |
| ------------ | --------------------------------- | ---------------------------- |
| TC_LOGIN_001 | Login with valid email & password | 200 OK, token generated      |
| TC_LOGIN_002 | Login with active user            | User redirected successfully |
| TC_LOGIN_003 | Check response time               | Response < 2 sec             |

| Test Case ID | Scenario                 | Expected Result       |
| ------------ | ------------------------ | --------------------- |
| TC_LOGIN_004 | Invalid password         | 401 Unauthorized      |
| TC_LOGIN_005 | Invalid email format     | Validation error      |
| TC_LOGIN_006 | Empty email/password     | Mandatory field error |
| TC_LOGIN_007 | SQL Injection input      | Request blocked       |
| TC_LOGIN_008 | Login with inactive user | Access denied         |

Postman Test Script

pm.test("Status code is 200", function () {
    pm.response.to.have.status(200);
});

pm.test("Response contains token", function () {
    var jsonData = pm.response.json();
    pm.expect(jsonData.token).to.exist;
});

pm.test("Response time is less than 2s", function () {
    pm.expect(pm.response.responseTime).to.be.below(2000);
});
